# Заняття 2: Колекції, Generics та LINQ

## Задача 8: Відкладене виконання (Deferred Execution)
1. Що виведе код до запуску і чому?
   Код виведе числа: 3, 4, 5, 6, 7. Це відбувається через механізм *відкладеного виконання* в LINQ. Запит Where(...) не виконується в момент його оголошення. Він починає працювати тільки тоді, коли ми ітеруємося по ньому в циклі foreach. Оскільки елементи 6 та 7 були додані до колекції до початку роботи циклу, LINQ-запит побачив повний оновлений список і відфільтрував усі елементи, що більші за 2.

2. Що зміниться, якщо додати `.ToList()` після `Where(...)`?
   Якщо викликати .ToList(), запит виконається *миттєво (Eager Execution)* прямо на поточному стані списку. У змінну query збережеться новий окремий список із елементами 3, 4, 5. Наступні виклики numbers.Add(...) вже ніяк не вплинуть на результат, тому на екран виведеться лише 3, 4, 5.
